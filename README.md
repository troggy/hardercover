# Hardercover

Chrome/Brave/Chromium extension to improve user experience on hardcover.app. [Hardcover](https://hardcover.app/) is a great indie alternative to Goodreads. Give it a try.

## Features

### Show links to Libgen and Flibusta for book editions

So that you can easily download the book to check it out. This is only for previewing contents of the book, if you are going to read the book, please go and buy it to support the author.

## Installing

### From Chrome Web Store

not yet published

### From Github releases

1. Download and unpack latest zip file from Github Releases
2. Set your Chrome browser 'Developer mode' up
3. Click 'Load unpacked', and select folder with unpacked extension

### From sources

1. `pnpm i`
2. `pnpm build`
3. Set your Chrome browser 'Developer mode' up
4. Click 'Load unpacked', and select `hardercover/build` folder

## Developing

1. `pnpm i`
2. `pnpm dev`. Starts dev server watching for changes. Installed extension automatically reloads on each change
3. Set your Chrome browser 'Developer mode' up
4. Click 'Load unpacked', and select `hardercover/build` folder
